Artefact: MNIST Neural Network

Overview

This artefact documents my individual Machine Learning reassessment, which involved developing and evaluating an artificial neural network using the MNIST handwritten digit dataset. The project focused on classifying images of handwritten digits (0–9) using Python and TensorFlow/Keras in Google Colab. It demonstrates my understanding of data preparation, neural network development, model training and performance evaluation. The artefact also includes my presentation and transcript, which explain the methodology, results and limitations of the model.

Project Objectives

The objective of this project was to develop an artificial neural network capable of recognising and classifying handwritten digits from the MNIST dataset. The project aimed to explore how neural networks learn patterns from image data and evaluate their effectiveness using appropriate performance measures.

Methodology

The project was completed using Python in Google Colab, with TensorFlow and Keras used to develop and train the neural network.

The main stages included: 1. Data loading and exploration: Loading the MNIST dataset and examining sample handwritten digit images. 2. Data preprocessing: Normalising pixel values to improve the consistency of the input data. 3. Data partitioning: Separating the training data into training and validation sets, while retaining the separate test dataset for final evaluation. 4. Model development: Building an artificial neural network to classify images into ten digit categories (0–9). 5. Model training: Training the network over ten epochs and monitoring training and validation accuracy and loss. 6. Model evaluation: Assessing performance using test accuracy, a confusion matrix and analysis of misclassified images.

Results and Evaluation

The artificial neural network achieved a test accuracy of approximately 97.86%, demonstrating that it was able to correctly classify the majority of handwritten digit images. Out of the 10,000 images in the test dataset, 214 were incorrectly classified.

The training and validation results showed that the model learned effectively over the ten training epochs. The accuracy and loss graphs provided a way to monitor the model's learning progress and assess its performance on data that was not used directly for training.

Although the model achieved a high level of accuracy, it was not completely reliable. The remaining classification errors demonstrate that accuracy alone does not provide a complete picture of model performance. Examining misclassifications provided further insight into the model's limitations and the importance of evaluating machine learning systems beyond a single performance measure.

    Reflection

    Completing the MNIST project gave me the opportunity to apply machine learning concepts in practice and develop my understanding of artificial neural networks. Initially, I found some of the technical concepts and implementation stages challenging, particularly understanding how the model learned from the data and how its performance should be evaluated.

    Working through the project step by step helped me become more confident in using Python and Google Colab. I also developed a better understanding of the importance of data preprocessing, training and validation, and evaluating a model using different performance measures. One of the most valuable aspects was analysing the misclassified images. This helped me recognise that even a model achieving high accuracy has limitations and that examining errors is important when assessing its effectiveness.

    This project strengthened my confidence in applying machine learning techniques independently and improved my ability to interpret and communicate technical findings. It has also encouraged me to explore how similar analytical approaches could be applied to real-world healthcare data.
