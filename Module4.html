Module 4 — Machine Learning

Module summary: This module explores key machine learning concepts, algorithms and their practical applications in real world

data analytics. It combines theoretical knowledge with hands on implementation using tools such as Python and R, while

considering the challenges, limitations and ethical implications of machine learning.

Learning outcomes

  • Articulate the legal, social, ethical and professional issues faced by machine learning professionals.
  • Understand the applicability and challenges associated with different datasets for the use of machine learning algorithms.
  • Apply and critically appraise machine learning techniques to real world problems, particularly where technical risk and uncertainty are involved.
  • Systematically develop and implement the skills required to be an effective member of a development team in a virtual professional environment,
    • adopting real-life perspectives on team roles and organisation.
